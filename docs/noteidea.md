# LabFlow Notes 想法

## 目的

在每個 Experiment detail 裡加入一個非常簡單的 Notes 欄位，用來記錄零星、當下需要留下的資訊，例如秤重結果：`12.43 g`、`第二次 12.01 g`。它不是 Experimental Procedure，也不需要做成逐步實驗日誌。

## 建議介面

每個 Experiment 一個自由文字欄位：

```text
Notes
[ 12.43 g；第二次 12.01 g ]
```

輸入後自動保存，不需要額外的 Save 按鈕。

## 公司網路限制

公司網路可能封鎖 Supabase 或登入服務，因此 Notes 應採用 local-first：

- 輸入後立即保存到瀏覽器本機。
- 無法登入或後端無法連線時仍然可以使用。
- 線上且已登入時自動同步到後端。
- 離線期間標記為待同步。
- 網路恢復後重新驗證並上傳待同步內容。
- Export ZIP 一起包含 Notes，作為額外備份。

## 第一版範圍

先只做單一純文字欄位，不做時間軸、標籤、附件或複雜同步衝突。Notes 的用途是快速留下重量、觀察值或零星提醒。

如果瀏覽器資料被清除、換電腦或換瀏覽器，本機資料可能消失，因此 Export 仍然要保留。
